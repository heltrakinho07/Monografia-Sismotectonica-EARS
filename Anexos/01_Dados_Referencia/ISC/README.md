# ISC — Catálogo de Referência 2010–2013

Esta pasta contém o **catálogo de referência do International Seismological Centre (ISC)** utilizado na monografia para comparação e validação dos resultados do workflow automático.

## Conteúdo esperado

- `ISC_catalogo_de_referencia_2010_2013.*` — catálogo ISC correspondente ao período de 2010 a 2013.

## Finalidade

O catálogo aqui armazenado constitui **dado externo de referência** e não um resultado produzido pelo workflow da monografia.

Sempre que o ficheiro for adicionado, recomenda-se registar:
- formato do ficheiro;
- data de obtenção;
- período temporal;
- filtros espaciais aplicados;
- eventuais transformações ou limpeza realizadas antes da comparação.
