# 03 — EQTransformer

## Objectivo
Executar a detecção automática de sinais sísmicos e o picking das fases P e S.

## Estrutura prevista
- `scripts/`
- `configs/`
- `notebooks/`
- `examples/`

## Outputs principais
Picks P/S, probabilidades, detecções, estatísticas e figuras de controlo de qualidade.

Os resultados seleccionados para a monografia devem ser organizados em `Extra/01_EQTransformer/`.
