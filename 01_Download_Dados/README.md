# 01 — Download dos Dados

## Objectivo
Reproduzir a aquisição e organização inicial das formas de onda e metadados.

## Estrutura prevista
- `scripts/` — rotinas de download;
- `configs/` — redes, estações, canais, datas e endpoints;
- `metadata/` — inventários pequenos e tabelas de estações.

## Outputs
Os dados brutos devem ficar fora do Git e ser referenciados por configuração/documentação.
