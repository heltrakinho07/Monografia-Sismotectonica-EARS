# 02 — Pré-processamento

## Objectivo
Preparar os dados para detecção automática e garantir consistência temporal e instrumental.

## Estrutura prevista
- `scripts/` — validação, conversão, filtragem e organização;
- `configs/` — parâmetros de processamento;
- `examples/` — exemplos mínimos para teste.

Registar sempre qualquer filtro, resampling, remoção de resposta instrumental, normalização ou corte temporal aplicado.
