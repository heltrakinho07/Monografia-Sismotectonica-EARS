# Resultados Finais da Monografia

Produtos consolidados e versões finais utilizadas na monografia.

Incluem, quando aplicável:
- catálogo sísmico final;
- catálogo relocalizado;
- catálogo com clusters;
- tabelas extensas;
- mapas finais;
- figuras;
- estatísticas;
- ficheiros suplementares citados no texto.

Sempre que possível, os ficheiros desta pasta devem corresponder exactamente às versões citadas na monografia.
